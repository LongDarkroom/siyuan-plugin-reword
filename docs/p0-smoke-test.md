## 7. 错误路径

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 7.1 | 粘贴不识别格式（如"@#$%^"） | 提示"未识别格式" + 列 5 种格式约定 |
| 7.2 | 粘贴只有停用词（"the / a / an"） | 解析成功但全部跳过（0 词） |
| 7.3 | 粘贴重复词 | 去重，词数正确 |
| 7.4 | 粘贴超长行 | 跳过 + 报告 skippedCount |
| 7.5 | 校验 ALL_BOOK_ID（虚拟聚合）| 返 false（拒绝） |
| 7.6 | 校验不存在的 bookId | 返 false（拒绝） |

**通过条件**：
- [ ] 错误提示清晰
- [ ] 不会破坏数据
