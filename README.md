# RE word · 思源英语词汇与 AI 精读助手

RE word（siyuan-plugin-reword）是思源笔记（SiYuan）的英语学习插件，集**离线词典查词、生词标注与复习、AI 精读**于一体。

> 插件内置离线查词引擎与 AI 精读两大能力，无需联网即可查词，AI 精读部分需要配置你自己的大模型 API Key。

## 核心功能

### 1. 离线词典查词
- 选中英文单词一键弹出词典卡（音标、词性、释义、例句）。
- 自带 **MDX 离线词典引擎**，支持加载新世纪英汉大词典等 `.mdx` 词库（25 万+ 词条）。
- 自带离线音标补全表与词形还原（复数、过去式等），查词更准。

### 2. 生词标注与复习
- 一键将选中词收入「词库文档」，自动捕捉上下文句。
- 单词以思源列表块 + 自定义块属性（音标 / 释义 / 掌握度 / 状态）存储，可被全文搜索与 SQL 查询。
- 词库面板支持搜索、筛选、掌握度管理与 CSV 导出。
- 浏览器原生 Web Speech API 朗读。

### 3. AI 精读
- **学习模式**：把选中内容结构化精读（释义、长难句、背景），一键入库词库 / 写入批注。
- **对话模式**：就选中内容自由问答。
- 支持把**思源文档页签 / 文档树直接拖入对话框**作为全文上下文，发送时实时拉取最新文档内容。
- 内置预设提示词模板，一键填充到输入框。

## 安装

### 集市安装（推荐）
在思源笔记「集市 → 插件」搜索 **RE word** 安装。

### 本地安装
1. 下载 `package.zip`（GitHub Release 附件）。
2. 思源笔记「设置 → 集市 → 本地安装」，选择该 zip。

## 离线词典说明

插件支持多种离线词库（`.mdx`）。首次使用可在插件设置中**下载/导入词库**：
- 内置引导下载常用英汉词典；词库文件保存在插件目录的 `dict/`，**不随插件包分发**（体积较大），按需下载即可。
- 也可放置自有 `.mdx` 词库到该目录。

## 开发

```bash
npm install
npm run dev      # watch 模式构建到 dist/
npm run build    # 构建并同步到插件目录
npm run make     # 构建 + 生成社区集市 package.zip
npm run test     # 运行单元测试
```

## 技术栈
- TypeScript + Vite + Svelte
- 思源插件 SDK（`siyuan` npm 包）
- 思源块属性 API + SQL 查询 API
- 自研 MDX 离线词典引擎（js-mdict）
