# RE word 词汇助手

RE word 是思源笔记（SiYuan）的英语学习插件，主打 **离线查词 + 智能收词复习 + AI 精读**。所有词典均为本地离线查询，不依赖外部网络。

## ✨ 核心功能

- **选中即查词**：在任意文档中划选英文单词，一键查询离线词典，无需联网。
- **快捷键收词**：框选后快捷键自动加入生词本，配合间隔复习巩固记忆。
- **AI 精读**：把选中文本交给 AI（学习 / 对话两种模式）做深度解析与双语对照。
- **自定义离线词典**：支持 MDX / StarDict 格式，可加载你自己的词库。
- **文档即上下文**：把思源文档页签拖入 AI 对话框，作为精读上下文。

## 📦 词典包获取指南

> 本插件 **不内置任何词典数据**，需要你自行准备离线词典包（MDX 或 StarDict 格式）后才能查词。

👉 详细的词典包获取与配置方式，请看这篇指南：[如何获取 / 配置 RE word 词典包](https://ld246.com/article/1787911845417)

## 🔧 安装词典

在 RE word 的「词典管理」对话框中，有两种导入方式：

1. **导入对话框（推荐）**：下载 `.mdx` 原包 → 打开词典管理 → 点「导入」→ 选择文件，插件会自动写入 `dict/` 目录并建索引启用。
2. **手动放置**：把 `.mdx`（或 StarDict 的 `.ifo` / `.idx` / `.dict` / `.dict.dz`）直接放入插件目录 `data/plugins/siyuan-plugin-reword/dict/`，然后在对话框点「刷新」重载。

> ⚠️ 版权提示：请仅使用你拥有合法授权的词典包（如公版词库、自整理词表），勿分发受版权保护的商业词典。

## 📋 快速上手

1. 安装插件并配置至少一个离线词典（见上方指南）。
2. 在任意文档中划选英文单词即可查词。
3. 用快捷键把生词加入复习计划。
4. 需要深度理解时，选中段落交给 AI 精读。
